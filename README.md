## 🌟 مميزات وهيكل الدورة الإدارية المتكاملة (Business Cycle)

```text
[العميل يتعاقد مع المبيعات]
          ↓
[المبيعات تسجل الطلب ومواصفات الكوڤير (BOM) وترسله للتشغيل]
          ↓
[مدير التشغيل يفحص الخامات ويطلب صرف المستلزمات من المخزن المركزي]
          ↓
[المخزن المركزي]: إما توفر الخامات وصرفها بسند رسمي
               أو إحالة النواقص للمشتريات
          ↓
[مدير المشتريات يحدد مدة التوريد للخامات الناقصة]
          ↓
[إدارة التشغيل تحدد موعد التسليم الدقيق بناءً على زمن التوريد وسرعة الماكينات]
          ↓
[المبيعات تؤكد موعد التسليم النهائي للعميل مع إصدار فاتورة المبيعات]
          ↓
[الحسابات والمالية]: مراقبة التكاليف الثابتة والمتغيرة، احتساب هامش 14% للمصانع، 
                    وتفعيل جرس إنذار الخسارة (Loss Alarm) للأسعار الثابتة.
```

### 1. إدارة المبيعات وخدمة العملاء (Sales & CRM):
* إدارة بيانات العملاء مع لوجوهات وتصاميم الشركات الفعلية (كشري أبو طارق، واحة عمر، كبدة الفلاح، أسماك قادوس، كريب بايت، برجر ستيشن).
* تخصيص مكونات أطقم الكوڤير لكل عميل (معلقة، منديل جاف، منديل معطر، خلة، شوكة، سكين، غلاف مطبوع أو شفاف).
* إرسال الطلبيات لإدارة التشغيل وتأكيد مواعيد التسليم المعتمدة بعد فحص الخامات.

### 2. إدارة التشغيل والإنتاج (Operations & Production):
* تحويل طلبات المبيعات إلى أوامر تشغيل لخطوط الإنتاج.
* طلب صرف مستلزمات الإنتاج من المخزن المركزي بضغطة زر.
* متابعة خطوط الإنتاج والماكينات، وتسجيل تقارير ساعات العمل اللحظية (الإنتاج الفعلي، سرعة السير، التوقفات وكفاءة OEE).

### 3. إدارة المخازن المركزية (Central Warehouse):
* جرد يومي متكامل لـ 3 قطاعات: **المواد الخام ومستلزمات الكوڤير**، **المنتج التام**، و**قطع غيار الماكينات**.
* إصدار وأرشفة وطباعة سندات الصرف والاستلام الرسمية.
* إمكانية تحويل أي نواقص في طلبات الصرف مباشرةً إلى قسم المشتريات.
* إمكانية بيع الخامات للغير بهوامش ربحية معتمدة.

### 4. إدارة المشتريات وسلاسل الإمداد (Procurement):
* استقبال طلبات النواقص من المخازن وتحديد مهلة التوريد (Lead Time).
* إصدار أوامر شراء للموردين الخارجيين.
* إصدار أوامر شراء داخلية للمصانع التابعة للشركة محملة بـ **14% تكاليف إنتاج**.
* استلام الشحنات وتوريدها للمخزن المركزي آلياً.

### 5. الإدارة المالية والتكاليف (Finance & Cost Centers):
* فواتير وسندات القبض والصرف، وتتبع المصروفات الثابتة (رواتب، إيجارات، مرافق) والمتغيرة.
* محرك تسعير المنتجات وحساب تكلفة الـ BOM الحقيقية.
* **شاشة جرس إنذار الخسارة (Loss Alarms):** مراقبة العقود المباعة بأسعار ثابتة دون التكلفة الفعلية لتنبيه الإدارة العليا وتحديث الأسعار مستقبلاً.

### 6. المصانع والخطوط المستقلة كـ مراكز ربحية (+14%):
النظام يتعامل مع كل خط كمصنع مستقل لمعرفة نقاط القوة والضعف وأرباح كل خط:
1. **مصنع الكوڤير (المنتج الأساسي)**
2. **ماكينة ومصنع قص الجوانتيات**
3. **مصنع تعبئة وتغليف الجوانتيات**
4. **مصنع حقن البلاستيك (ملاعق وشوك - تصنيع عند الغير)**
5. **مصنع رولات التغليف والطباعة (سيلوفان مطبوع - تصنيع عند الغير)**
6. **مصنع الوايبس والمناديل المعطرة**

## 🚀 دليل الرفع والتشغيل على هوستينجر (Hostinger Deployment Guide)

### الخيار أ: الرفع على سيرفر هوستينجر السحابي الخاص (Hostinger VPS - KVM) [موصى به للإنتاج]

1. **الدخول للسيرفر عبر SSH:**
   ```bash
   ssh root@your-server-ip
   ```
2. **استنساخ المستودع:**
   ```bash
   cd /var/www
   git clone https://github.com/AsmaelShowky70/Alfa-Egypt-ERP-SYSTEM.git alfa-erp
   cd alfa-erp
   ```
3. **تثبيت الاعتماديات وإعداد البيئة:**
   ```bash
   composer install --no-dev --optimize-autoloader
   cp .env.example .env
   php artisan key:generate
   ```
4. **تجهيز قاعدة البيانات والصلاحيات:**
   ```bash
   # قاعدة بيانات SQLite الجاهزة أو MySQL:
   chmod -R 775 storage bootstrap/cache database
   chown -R www-data:www-data storage bootstrap/cache database
   
   # تشغيل التهيئة والبيانات الأولية إذا لزم الأمر:
   php artisan migrate --force --seed
   php artisan storage:link
   ```
5. **توجيه الـ Nginx / Apache:**
   اجعل `root` يشير إلى مسار: `/var/www/alfa-erp/public`.

---

### الخيار ب: الرفع على استضافة هوستينجر المشتركة (Hostinger Shared / Business Web Hosting)

1. **من لوحة تحكم هوستينجر (hPanel):**
   * اذهب إلى **Advanced** > **GIT**.
   * اختر إنشاء مستودع جديد وضع رابط هذا المستودع:
     `https://github.com/AsmaelShowky70/Alfa-Egypt-ERP-SYSTEM.git`
   * اختر المسار الفرعي المراد النشر فيه (مثلاً `alfa-erp`).
2. **إعدادات النطاق (Document Root):**
   * من تبويب **Websites** > اضغط على النطاق أو النطاق الفرعي.
   * عدّل مسار **Document Root** ليكون:
     `public_html/alfa-erp/public` (أو انقل محتويات المشروع بحيث يشير النطاق إلى مجلد `public`).
3. **عبر مدير الملفات (File Manager) أو SSH:**
   * أنشئ ملف `.env` بنسخ محتوى `.env.example`.
   * شغل أمر توليد المفتاح:
     ```bash
     php artisan key:generate
     php artisan migrate --force --seed
     ```
   * تأكد من إعطاء صلاحيات الكتابة لمجلدي `storage` و `bootstrap/cache`.
